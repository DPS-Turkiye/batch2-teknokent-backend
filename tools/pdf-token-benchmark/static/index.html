Metric definitions & scope

  • Tokens are API-reported input plus output tokens.
  • Cost uses rates embedded in the benchmark script.
  • Latency is end-to-end request time.
  • Differences are local text minus direct PDF.

Limitations

  • CV structure, scan quality, caching, and network conditions affect results.
  • Usage metrics do not establish extraction accuracy.
  • Reverse call order before generalizing.
